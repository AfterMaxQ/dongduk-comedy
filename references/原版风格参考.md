# 原版风格参考

这份参考用于校准栋笃笑的**生成机制与舞台节奏**，不是句式模仿指南。

仓库中的 `原始栋笃笑/` 保存完整原始字幕，仅在需要更高风格贴合度、研究长篇结构、验证某种节奏是否自然时抽样阅读。不要把所有原稿一次性灌入上下文，也不要复制现成笑点、经典句式、标志性口头禅或可识别桥段。

## 一、要学的是“怎样长出笑点”

### 1. 先咬住一个很小的词或动作

高质量栋笃笑经常不是一上来抛大观点，而是抓住一个普通词、一个现场反应、一个动作，然后不断追问它真正意味着什么。

常见生长方式：

> 小词 / 小动作 → 改定义 → 按新定义继续推演 → 推到另一个生活领域 → 再回到原词

重点不是“比喻很怪”，而是新定义真的能解释后续行为。

### 2. 观众是素材，不是背景

现场反应、叫喊、掌声不足、有人插嘴、有人提要求，都可以立即进入作品。

处理原则：

- 先承认现场发生了什么；
- 再把观众行为重新解释；
- 最后把这个解释变成当前段落的一部分。

不要机械写“观众笑”。只有当观众行为会改变下一句时，才写互动。

### 3. 转场靠“上一句还没死”

自然转场通常不是“下面讲另一个话题”，而是上一段中的某个：

- 词；
- 人物；
- 物件；
- 情绪；
- 逻辑；
- 误会；

继续往下长，于是看似换题，其实仍是同一条思路。

写长篇时尤其要追问：

> 上一句里面，有什么东西还能继续活？

### 4. 一本正经地把歪理做完整

笑点不是“说一个荒唐结论”，而是先接受一个错误但貌似合理的前提，再认真把它贯彻到底。

一个好的推演至少经历两次变化：

- 第一次：观众发现“这个定义居然说得通”；
- 第二次：这个定义扩张到别的场景，开始失控；
- 第三次可选：讲者自己也被这套逻辑击中。

### 5. 讲者必须可以出丑

不要把叙述者写成全知社会评论员。

高质量自嘲不是一句“我都一样啦”，而是要给出证据：

- 自己也贪钱；
- 自己也虚荣；
- 自己也怕输；
- 自己明知不合理仍照做；
- 自己前面讲的原则，后面亲自违反。

这样观众笑的不是“别人真蠢”，而是“原来大家都一样”。

## 二、粤语舞台节奏

### 1. 允许半句、改口、复述

真实舞台口语不应像出版文章。

可以保留有功能的：

- “唔係，等阵先……”；
- “你谂下先……”；
- “我唔係话……我係话……”；
- 讲到一半自己推翻；
- 同一句短词第二次出现时改变语气。

但不要为了“像粤语”而堆无意义语气词。

### 2. 长短句要有落差

常见节奏：

> 两三句很短 → 一段认真推理 → 突然一句极短 punchline。

不要每句话都抢做 punchline。连续强打会失去呼吸，也失去后面真正重拳的落差。

### 3. Act-out 要分角色逻辑

角色切换不是换几个口头禅。

每个角色必须有清楚立场：

- 讲者想证明什么；
- 对方想保护什么；
- 双方分别误解了什么。

只要立场稳定，哪怕对白很短，也会有舞台感。

## 三、长篇专场最重要的原版特征

### 1. 开场先建立“今晚这里发生什么”

完整专场不是直接进入主题。先建立：

- 今晚观众与讲者是什么关系；
- 当前演出有什么特殊处境；
- 观众可以怎样回应；
- 哪个现场词、动作或梗有机会成为后面的回调资产。

### 2. 主题不是章节，是污染

工作、爱情、钱、家庭、身份等主题应互相污染。

例如前面讲钱时发明的一个逻辑，后面可以拿来解释爱情；前面讲观众时产生的一个词，后面可以解释人生选择。

如果每个话题都能独立剪出来且不依赖前文，说明整场连贯度不足。

### 3. Callback 要“变义”

回调不是重复旧句，而是：

> 同一个词 / 物件 / 人物，在新上下文里突然获得第二层意义。

后半场应越来越多出现“只有听过前面才会笑得更大声”的瞬间。

### 4. 尾声不是总结

不要把整场变成演讲。

更好的结束方式是：

- 回收开场的小东西；
- 让讲者自己落入前面批判的逻辑；
- 用一句很轻的话完成前文很重的东西；
- 或者让一个旧笑点突然带出新的情绪。

## 四、原稿抽样策略

需要风格校准时：

1. 先读本文件；
2. 再从 `原始栋笃笑/` 随机或按任务选择 1～2 份原稿；
3. 每份只抽样几个相隔较远的片段：开场、一个中段、一个后段；
4. 只记录结构特征，不记录可复用句子；
5. 创作时回到用户主题，重新建立原创场景和原创逻辑。

### 任务与抽样重点

- **短段子**：重点看单一前提怎样升级；
- **粤语口语**：重点看停顿、复述、角色切换；
- **整场专场**：重点看开场互动、跨主题转场、后半场回调；
- **社会议题**：重点看怎样先落到个人经历与具体物件，再扩展观点。

## 五、禁止误学

不要把以下表面特征当成“原版风格”：

- 每几句爆粗；
- 不断喊观众；
- 每段都政治或社会批判；
- 每段都重新定义一个词；
- 每个结尾都突然哲学；
- 粤语语气词越多越像；
- 把旧段子换名词后重新使用。

真正要保留的是：**具体观察、严密歪理、现场意识、自我暴露、自然转场、长期回环。**
