# dongduk-comedy

一个用于创作中文与粤语观察型栋笃笑的 Agent Skill。

当前支持：

- 随机漫游：用户不提供主题时自动从具体生活摩擦中选题；
- 单话题：围绕一个主题创作可独立表演的完整段落；
- 整场中的局部段落：承接上一段并为下一段留下自然入口；
- 完整专场：支持 40,000 字以上长篇结构，维护 Show Bible、Segment Map、Callback Ledger 与 Stage State；
- 原版风格校准：从仓库中的原始栋笃笑字幕抽取高层创作机制，不复制现成笑点与标志性表达。

## 使用

把仓库作为 Skill 目录加载，入口文件为 `SKILL.md`。

需要更高原版风格贴合度时，Skill 会先读取 `references/原版风格参考.md`，必要时再抽样读取 `原始栋笃笑/` 中的字幕文件。
